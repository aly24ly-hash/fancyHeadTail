# fancyHeadTail
New command combining the roles of head and tail. Reads not just the starting and ending line, but a whole section of code based on the lines you input.

I asked AI to help me create a new fancy command using some of the commands we explored in class. A few ideas were given and I really liked the idea of combining head and tail. AI helped me when I ran into an error and some issues. For example, when I had an issue with the command lines because code lines start at 0 and not 1. AI helped open my eyes to that possibility. One that didn't occur to me. I thought of one of the test cases on my own (the first one) and I only had AI help me to explain and better describe the behavior and output. Throughout my project, AI also didn't provide me a solution to my command line issue right away. Instead I had to look at it myself and figure out what was setting it back. Overall, I don't believe AI really got anything wrong but rather helped me smoothly run my code and create my new fancy command.
